# 🚀 Xsmash - AI for Termux

Xsmash adalah asisten coding AI berbasis Command Line Interface (CLI) yang dirancang khusus untuk berjalan di atas **Termux (Android)**. 

Proyek ini **dikembangkan oleh RuningByte**. Xsmash memungkinkan kamu untuk bertanya seputar koding, debugging, atau meminta *generate* script langsung dari terminal HP kamu tanpa harus buka browser.

## ⚙️ Cara Kerja

Xsmash tidak menjalankan model AI raksasa di dalam HP kamu (karena itu bakal bikin HP nge-hang). Xsmash bekerja sebagai *interface* terminal yang ringan, lalu mengirim pertanyaan kamu ke server AI menggunakan **API Key**. Dengan begitu, HP kamu tetap ringan, tapi otak AI-nya tetap jenius!

## 🛠️ Persyaratan Sistem

- Aplikasi **Termux** (dapat diunduh dari F-Droid).
- Koneksi internet yang stabil.
- **API Key** (Saat ini default menggunakan Groq API yang gratis)
